# Library-Management-System

A university course project: a Library Management System that manages books
and their individual physical copies, borrow requests, reservations, waiting
queues, loans, return and renewal requests, due dates, renewal eligibility and
fines, user profiles, in-app notifications, audit records, and database
backups — starting as a console application, with a REST API and a web
interface planned for later phases.
